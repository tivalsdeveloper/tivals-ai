# Tivals AI

A mobile-friendly AI assistant interface powered by tivalsdeveloper.

## Features
- No sign-in or login
- Responsive AI chat UI
- Local conversation history
- New chat control
- Ready for a secure `/api/chat` backend

## AI backend
The frontend intentionally does not contain an API key. Connect `/api/chat` to a serverless/backend endpoint and store the provider API key as a server-side environment variable.

## GitHub Pages
Publish the repository from the `main` branch in Settings → Pages. Note that GitHub Pages is static hosting, so a server-side AI API must be hosted separately or proxied through a serverless service.
